# ESP MicroPython Multi-Tool

A MicroPython-based project for ESP microcontrollers featuring network tools and games.

## Features
* Evil Twin Access Point
* Evil Portal (Captive Portal)
* Tetris Game
* Support for ILI9341 and ST7789 displays with XPT2046 touch controller

## Requirements
* ESP microcontroller (e.g. ESP32)
* MicroPython firmware
* ILI9341 / ST7789 TFT Display

## Installation
Upload all files and folders to the root directory of your ESP device using your preferred MicroPython DEA/IDE (like Thonny, ampy, or mpremote).

## Usage
Run `main.py` on boot.
